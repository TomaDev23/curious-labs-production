# create-art — the art bridge

Text-free art is generated by `tools/art/generate.mjs` (OpenAI Images API), turned into web assets
by `tools/art/export.mjs` (sharp), and shown to the owner with `tools/art/contact.mjs`. The website
draws all words as real HTML **on top** of this art — images never contain copy.
All paths are relative to the repo root (`C:\curious-labs-production1`). Commands run the same in
the Bash tool or PowerShell (one command per line — PowerShell has no `&&`).

> **Route update (owner, 2026-09-13):** finals are produced by the **Codex builder's built-in image tool** via
> `Docs_v8/page_Consultation/cinematic_v1/ART_QUEUE.md` (prompt files in `tools/art/prompts/`, raw PNGs land as
> `tools/art/_raw/codex-<id>-vN.png`). The paid API here is for **cheap low-quality drafts only** — high-quality API
> renders cost ~11× more output tokens (measured: 12 high ≈ 77k vs 38 low ≈ 7k). Curating, `export.mjs`, contact
> sheets and provenance are unchanged. Codex output is tool-managed (seen: 1536×1024), so reserve native 2560px API
> renders for full-bleed hero-scale art and only with owner OK.

## Setup (already done — just check)

The key lives in `tools/art/.env` as `OPENAI_API_KEY=...`, gitignored twice (root `.env` rule +
`tools/art/.gitignore`). No npm install: Node 24 `fetch` + the repo's existing `sharp`.

```bash
git check-ignore -v tools/art/.env tools/art/_raw/x.png
```

Both lines must print a matching rule. If `tools/art/.env` is missing, ask the owner for a key —
never commit one, never paste one into another file.

## Workflow (agent path)

The commands below are the exact ones verified on 2026-09-13; the `_raw/...` file names are from
that run (they exist on the owner's machine, not in git). Swap in your own slugs, prompts and files —
and don't leave `zz-skill-verify*` files in `public/` (they were deleted after verification).

**1. Draft at low quality** (cheap, ~15–25 s each). Name = slug; output lands in `tools/art/_raw/`.

```bash
node tools/art/generate.mjs --name walls-landscape --quality low --size 2048x1152 --prompt "Dark alien rocky plateau at night under a star field ... Leave the upper third calm for text. No text, no letters, no logos, no people."
```

**2. Keep a set consistent** — pass the approved anchor image as `--ref` (switches to the edits
endpoint; the prompt should say what to take from it):

```bash
node tools/art/generate.mjs --name verify-ref-walls --quality low --size 1536x1024 --ref tools/art/_raw/test-earth-horizon-2026-09-13T05-26-34.png --prompt "Using the reference image only for colour grade and lighting (deep navy-black space, cyan rim light, warm gold sunrise glow): a dark alien rocky plateau at night ... No text, no letters, no logos, no people."
```

**3. Phone version = its own portrait generation**, not a crop of the landscape:

```bash
node tools/art/generate.mjs --name verify-portrait --quality low --size 1152x2048 --prompt "Tall portrait composition: a dark alien rocky plateau at night ... No text, no letters, no logos, no people."
```

**4. Cutouts** (door leaves, figures, slabs) — transparent background:

```bash
node tools/art/generate.mjs --name test-silhouette --quality low --size 1024x1536 --background transparent --prompt "Full-body silhouette of a lone person seen from behind ... Isolated cutout subject on a fully transparent background. No ground, no scenery, no text, no logos."
```

**5. Contact sheet → show the owner before anything goes in the page** (alpha shows on a magenta checker):

```bash
node tools/art/contact.mjs tools/art/_raw/verify-ref-walls-2026-09-13T05-34-09.png tools/art/_raw/preview/walls-draft-mobile.webp tools/art/_raw/test-silhouette-2026-09-13T05-27-32.png --out tools/art/_raw/contact-sheet.png --cols 3 --tile 420
```

Then `Read` the PNG yourself (you can see it) and send it with `SendUserFile`.

**6. Approved → re-run the same prompt at `--quality high`** (and the final size), then export.
Preview exports go to `_raw/preview`; finals go to the default `public/consultation/`:

```bash
node tools/art/export.mjs --in tools/art/_raw/verify-ref-walls-2026-09-13T05-34-09.png --out walls-draft --desktop 1920x1080 --mobile 900x1600 --focus centre --darken 0.1 --dest tools/art/_raw/preview
node tools/art/export.mjs --in tools/art/_raw/verify-size-max-2026-09-13T05-35-36.png --out zz-skill-verify --desktop 2560x1440 --darken 0.08
node tools/art/export.mjs --in tools/art/_raw/verify-portrait-2026-09-13T05-36-15.png --out zz-skill-verify --mobile 1080x1920 --focus south
node tools/art/export.mjs --in tools/art/_raw/test-silhouette-2026-09-13T05-27-32.png --out zz-skill-verify-cutout --alpha --dest tools/art/_raw/preview
```

Two runs with the same `--out` give `<slug>-desktop.*` from the landscape and `<slug>-mobile.*` from
the portrait. The printed table flags files over the budget (default 250 KB). Vite serves
`public/` at the root, so the page references `/consultation/<slug>-mobile.avif` etc. (verified 200
from the dev server).

| script | flags |
|---|---|
| `generate.mjs` | `--name` `--prompt`/`--prompt-file` `--quality low\|medium\|high` `--size WxH` `--background transparent` `--ref a.png,b.png` `--n` `--model` (default `gpt-image-2`) |
| `export.mjs` | `--in` `--out` `--desktop WxH` `--mobile WxH` `--focus centre\|north\|south\|east\|west\|attention` `--darken 0–1` `--alpha` `--budget KB` `--dest` |
| `contact.mjs` | `<images…>` `--out` `--cols` `--tile` |

Every call is logged to `tools/art/_raw/log.jsonl` (prompt, size, quality, token usage).

## Rules (owner + locked brief)

- **No text, letters, logos, UI or watermarks** in any image. Say so in every prompt. Leave calm
  negative space where copy will sit.
- **Low quality for drafts and placeholders; high quality only for approved finals.** The owner
  tops up funds as needed — image generation is cheap, but report how many images a batch will make.
- **The build plan is the art authority:** `Docs_v8/page_Consultation/cinematic_v1/CuriousLabs_Consultation_Cinematic_Build_Plan_v1.0.md`
  ("Artwork register" — ART-01…ART-10 give size, text-safe zone and brief per asset). Name slugs by ART ID (`art-01-earth-horizon`).
- **No people at all by default** — no portrait, no silhouette, no from-behind explorer standing in for the owner (ART-09, SC-03, SC-05). Only an owner-supplied real photo, later.
- **Never generate a place that must be real.** ART-05 "Phnom Penh at night" is an owner-supplied or licensed photo, not generated; generated city mood art must never be labelled as a real place.
- Palette: deep navy/black space, cyan atmospheric rim light, warm sunrise gold. Lime is UI-only.
- Geography that must be correct (e.g. Cambodia's outline) is sourced SVG in code (ART-10), not trusted to the model.
- **Record provenance for every shipped file** (plan QA-27): add a row to `Docs_v8/page_Consultation/cinematic_v1/ART_PROVENANCE.md` — ART ID, exported files, model/quality/size, raw file, prompt, approval date. `_raw/log.jsonl` is gitignored, so it doesn't count.
- Raw generations stay in `tools/art/_raw/` (gitignored). Only exported finals in `public/` get committed — and only when the owner asks.

## Gotchas

- **Sizes must be divisible by 16** — `1000x777` → `OpenAI error 400: ... must both be divisible by 16.`
  gpt-image-2 renders **native 4K** (`3840x2160` verified, ~26 s at low) — never upscale; generate at the size you ship.
- **Cropping a landscape to 9:16 loses the subject** (the moon was cut off, the frame was mostly
  empty sky). Generate a separate `1152x2048` portrait for phones.
- **"Silhouette" gives a fully lit person seen from behind.** Ask for "backlit, pure black silhouette" explicitly.
- **`--ref` is expensive on input** (~1.5k image tokens per reference vs ~100 text) — use one anchor, not five.
- **Low-quality output is already near-final for dark space scenes**; quality mostly shows in fine detail (city lights, rock texture).
- **Never name the key file `.env.local`** — this repo's rule is `.env.*.local`, which does *not* match it. Never prefix `VITE_` (Vite inlines those into the client bundle).
- Models on this key also include `gpt-image-2.5-flare` / `-sunburst` (dated 2026-09-08) — untested; try with `--model` if gpt-image-2 falls short.

- **High quality takes ~1–3 min per image** (1024² high measured 131 s). With the owner's **VPN on, any silent
  connection is cut at exactly 60 s** (`fetch failed … SocketError: other side closed`, `UND_ERR_SOCKET`, 0 bytes
  read) — low-quality calls finish under 60 s so they looked fine. `generate.mjs` therefore **streams by default**
  (`stream: true`, `partial_images: 3`, keeps bytes flowing) and retries network errors twice. Disable with
  `--stream false` only for debugging. A cut request may still have been billed.
- **Recreating an approved low draft at high quality:** pass the draft as `--ref` and prefix the prompt with
  "Recreate the reference image as a high-fidelity final: keep its exact composition…" — re-running the bare prompt gives a different picture.

## Troubleshooting

- **`Assertion failed: !(handle->flags & UV_HANDLE_CLOSING) ... exit 127`**: Node on Windows exiting
  via `process.exit()` right after `fetch`. Fixed in `generate.mjs` (uses `process.exitCode`); keep it that way in any new script.
- **`Missing ...tools\art\.env`**: the key file isn't there — ask the owner; don't create one from memory.
- **`OpenAI error 401`**: key rotated or revoked — owner supplies a new one into `tools/art/.env`.
