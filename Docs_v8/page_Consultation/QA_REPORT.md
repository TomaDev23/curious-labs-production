# QA report

**CuriousLabs AI consultation reference v0.3 · 9 September 2026**

## What was actually checked

The generated single-file HTML was rendered in **Chromium 144.0.7559.96** using Playwright's inline-document transport (`page.set_content`). **56 automated browser checks passed**. The detailed machine-readable results are in `tests/browser-results.json`.

The browser run checked page overflow and JavaScript errors at **320, 360, 390, 620, 768, 900, 1,024, 1,440, and 1,920 CSS pixels**. It recorded no external requests from the self-contained document. Selected phone, tablet, and desktop widths also checked that the homepage dialog fit without internal horizontal overflow and closed with Escape. The phone test verified that the primary CTA precedes the decorative visual.

Interaction checks covered independent reading rows, simultaneous open states, the biography link opening R4, close-to-summary focus restoration, build-note visibility, and the H1 contact shortcut closing its dialog and targeting D8. Keyboard Enter was tested on a reading summary. Reduced-motion checks verified that smooth scrolling and button transitions were disabled.

Content-state checks covered the two explicitly pending proof reserves, disabled unset contact destinations, approved valid-shaped synthetic contact values, invalid values failing closed, and the approval flag preventing activation even when destinations look valid. Synthetic values were not real user contact details; no destination was followed and no message was sent.

The clipboard-unavailable path was tested in the inline browser context. The successful-copy UI was tested with a stubbed clipboard, **not a real system clipboard/permission grant**. The no-JavaScript check verified that all eight main sections remain present, native reading disclosure works, and JavaScript-only review controls remain hidden.

## Structural and syntax checks

`tests/validate_reference.py` passed for the two complete modular HTML entry points. It checks unique IDs, one H1, internal and cross-document anchor existence, local asset existence, absence of runtime external asset references, D1–D8/R1–R4 ordering, six subject cards, two proof slots, reference indexing metadata, and safe unconfigured defaults. The consultation token/style files were checked against a global `:root` variable installation.

`node --check js/consultation.js` passed. The standalone file is generated by inlining the same CSS/JavaScript sources used by the modular page; it is not a separately rewritten implementation.

## Visual inspection

The desktop top and full-page render, mobile top/full-page render, homepage dialog, and representative enlarged section crops were inspected for reading order, panel clipping, excessive wrapping, and visual hierarchy. The reference shows real text and controls, not a flattened screenshot page. The desktop and phone views preserve the same D1–D8 sequence.

The chosen style is intentionally calmer than the dense strategic-board screenshots. It retains the palette, outlined panels, monospace labels, lime actions, and orbital graphic without importing every decorative label or making the entire page a terminal.

## Boundaries of this QA

Direct `file://` and localhost navigation were blocked by this environment's Chromium policy. The working document was therefore tested via inline rendering. The self-contained file has no external runtime assets, but its direct local-file opening transport was **not independently exercised in this environment**.

No current repository, production router, deployment configuration, actual brand asset/font, Safari, Firefox, physical phone, or assistive-technology session was tested. No Lighthouse score, performance certification, cross-browser certification, security audit, or full accessibility conformance is claimed.

No actual contact destinations or approved evidence assets were supplied. Ownership of addresses, QR payloads, real clipboard permissions, image redactions, and real proof-image availability/larger-view behavior remain integration/content checks. The image-rendering/lightbox code exists, but a genuine selected artifact was not available for a real-asset acceptance test.

The reference itself is **not publication ready**: identity/copy approval, selected or omitted evidence, and verified or omitted contact channels remain open. A production build must remove the review shell, notes, reserves, and source material rather than merely hiding this report.
